## 常用 {#basics}

```command
ls -la
```

| 寫法 | 做什麼 |
| --- | --- |
| `ls` | 列出目前目錄 |
| `ls 目錄` | 列出指定的目錄，例如 `ls ~/.log` |
| `ls -a` | 包含隱藏檔（`.` 開頭的檔案） |
| `ls -l` | 詳細資訊：權限、擁有者、大小、時間 |
| `ls -lh` | 大小顯示成 `4.0K`、`1.2M`，比較好讀 |
| `ls -la` | 最常用：詳細資訊 + 隱藏檔 |

### 讀懂 ls -l {#long-format}

```output
-rw-r--r-- 1 lab07 lab07 18 Nov 21 13:45 config.json
```

| 部分 | 範例 | 意思 |
| --- | --- | --- |
| 第 1 個字元 | `-` | `-` 檔案、`d` 目錄 |
| 接下來 9 個 | `rw-r--r--` | 權限，見 [檔案權限](/commands/permissions/) |
| 擁有者 / 群組 | `lab07 lab07` | 檔案屬於誰 |
| 大小 | `18` | 位元組 |
| 時間 | `Nov 21 13:45` | 最後修改時間 |

## 進階 {#advanced}

| 選項 | 做什麼 |
| --- | --- |
| `-t` | 依修改時間排序，最新的在前 |
| `-S` | 依大小排序，最大的在前 |
| `-r` | 反向排序 |
| `-R` | 連子目錄一起列出 |
| `-d` | 看目錄**本身**的資訊，而不是裡面的內容 |
| `-1` | 一行一個檔名 |

## 範例 {#examples}

```command
ls
ls -la
ls -lh ~/.log
ls -lt ~/.log
ls -ld ~/.ssh
```

1. 家目錄看起來是空的。
2. 加 `-a` 才看到 `.log` 與 `.config`。
3. 各個 log 的大小，`app.log` 最大。
4. 最近改過的排最上面。
5. 看 `.ssh` 目錄自己的權限。
