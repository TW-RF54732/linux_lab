## 常用 {#basics}

```command
cd ~/.log
```

| 寫法 | 做什麼 |
| --- | --- |
| `cd 目錄` | 進入目錄，例如 `cd .log` |
| `cd` 或 `cd ~` | 回家目錄 |
| `cd ..` | 往上一層 |
| `cd -` | 回到上一個所在的目錄 |
| `cd /` | 到最上層的根目錄 |

> [!TIP]
> 打路徑時按 [[Tab]] 會自動補完，按兩次會列出所有可能。可以避免大部分拼錯。

## 進階 {#advanced}

| 路徑寫法 | 意思 |
| --- | --- |
| `/` 開頭，例如 `/etc` | 絕對路徑，從根目錄算起，在哪裡打都一樣 |
| 其他，例如 `.log` | 相對路徑，從目前目錄算起 |
| `~` | 自己的家目錄 |
| `.` | 目前目錄 |
| `..` | 上一層 |

`cd` 是 shell 內建指令，要查說明用 `help cd`。

## 常見錯誤 {#errors}

| 訊息 | 原因 |
| --- | --- |
| `No such file or directory` | 路徑不存在。隱藏目錄記得加 `.` |
| `Not a directory` | 那是檔案，不是目錄 |
| `Permission denied` | 沒權限進入，例如別人的家目錄 |

## 範例 {#examples}

```command
cd .log
pwd
cd ~
cd ~/.config/app
cd -
```

1. 從家目錄進入 `.log`。
2. 確認位置。
3. 回家目錄。
4. 直接跳到設定檔所在的目錄。
5. 回到剛剛的家目錄。
