## 常用 {#basics}

```command
ssh 帳號@IP
```

| 寫法 | 做什麼 |
| --- | --- |
| `ssh 帳號@IP` | 登入 |
| `exit` | 登出，回到筆電 |
| `ssh -p 埠號 帳號@IP` | 伺服器不是用預設的 22 埠時 |
| `ssh -i 私鑰 帳號@IP` | 指定要用哪一把私鑰 |

登入後提示字元會變成 `lab07@linux-lab:~$`，這是判斷「現在在哪台電腦」最快的方法。

## 進階 {#advanced}

| 選項 | 做什麼 |
| --- | --- |
| `-v` | 顯示連線過程，金鑰登入失敗時用來找原因 |
| `-t` | 在遠端執行需要畫面的指令，例如 `ssh -t 帳號@IP less file` |
| `-L 本機埠:主機:埠` | 把遠端的服務轉到本機（埠轉發） |
| `-J 跳板` | 先連到跳板主機再連目的地 |
| `-o 設定=值` | 臨時改一個設定 |

連線卡住、`exit` 沒反應時：先按 [[Enter]]，再輸入 `~.`，會強制中斷。

## 範例 {#examples}

```command
ssh lab07@192.168.10.50
ssh lab07@192.168.10.50 'tail -n 3 ~/.log/app.log'
ssh -v lab07@192.168.10.50
```

1. 登入。
2. 不登入，只在遠端執行一個指令並取回結果。
3. 金鑰設好卻還要密碼時，看看哪裡出問題。

第一次連線的提示與常見錯誤見 [SSH 伺服器](/environment/sshd/)。
