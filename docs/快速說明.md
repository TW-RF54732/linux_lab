# Linux Server 社課 Lab：快速說明

一個 Proxmox CT（Ubuntu 24.04）上開 N 個學員帳號（`lab01`…），每人的環境裡有一個「故意壞掉」的服務 `lab-app`。學員透過 SSH 登入，看 log、找錯誤、修設定、重啟服務。

## 1. 課綱流程（約 75 分鐘）

用「app 掛了」的故事串起五段：你是新接手的維運，要找出原因、修好、確認恢復。

| 段 | 主題 | 時間 | 學員產出 |
| --- | --- | --- | --- |
| 1 | SSH 登入 | 10 分 | 說出自己的 `whoami`、`hostname` |
| 2 | SSH 金鑰登入 | 15 分 | 免密碼登入成功 |
| 3 | 找出問題 | 20 分 | `error.txt` 用 `scp` 拉回筆電 |
| 4 | 權限與執行腳本 | 10 分 | `chmod +x` 後 `./demo.sh` 執行成功 |
| 5 | 修復與服務 | 20 分 | `app.log` 最後出現 `INFO: started` |

各段重點：

1. **SSH 登入**：`ssh 帳號@IP`、fingerprint、提示字元分辨本機與遠端。
2. **金鑰登入**：`ssh-keygen` → `scp` 傳公鑰 → 寫入 `~/.ssh/authorized_keys` → `chmod` 600/700。
3. **找出問題**：`ls -la`、`less`、`grep ERROR`、`>` 與 `>>`、管線、`mkdir/mv/cp/rm`，最後 `scp` 下載報告。
4. **權限**：`id`、讀懂 `ls -l`、`/etc/shadow` 被拒絕，動手 `chmod +x` 執行 `~/.local/scripts/demo.sh`。
5. **修復**：用 `nano` 把 `~/.config/app/config.json` 的 `enable` 改成 `true` → `systemctl --user restart lab-app` → `tail ~/.log/app.log` 確認。

三個驗收點：免密碼登入成功、`error.txt` 拉回筆電、`app.log` 看到 `started`。

完整講師版：`docs/Linux Server 社課 教學流程（講師版）.md`

## 2. 挑戰關卡（challange）

課程之外的闖關：學員要解密拿到 flag。

流程：

1. 讀 `~/.challange/README.txt`，知道解密器是 `decoder.sh`、密鑰在 `/lab/key.txt`。
2. 執行 `decoder.sh` → Permission denied → `chmod +x`。
3. 解密器說找不到 `key.txt` → 把 `/lab/key.txt` 放進 `~/.challange/`（`cp`、`cat >>`、`ln -s` 都行）。
4. 解密成功產生 `flag.html`，約 1 秒後被背景程式 **evil-killer** 刪掉，並留下 `evil.txt`。
5. 讀 `evil.txt` → `systemctl --user status evil-killer` → `systemctl --user stop evil-killer`。
6. 再解密一次，`cat flag.html` 拿到 flag，用 `lab flag '<flag>'` 提交。
7. Bonus：把 `flag.html` 用 `scp` 拉回筆電、用瀏覽器開，看到隱藏的像素字，用 `lab bonus <文字>` 提交。

學員卡關時用 `lab hint`。課堂只教 `systemctl --user`，不教 `kill`。

規格：`docs/Linux Server 社課 challange 闖關規格.md`

## 3. `setup.sh`、`verify.sh`、`lab` 怎麼用

> `setup.sh`、`verify.sh` 和 `lab` 的講師功能都要在 **CT 裡以 root** 執行。

### 事前準備

```bash
cp lab.conf.example lab.conf   # 改學員人數、管理者帳號、時區等
```

### `setup.sh`：部署環境（可重複執行）

```bash
./setup.sh                      # 建立帳號、服務、設定檔；已存在的學員檔案不動
./setup.sh --reseed             # 全部學員的 log／設定／服務狀態重來
./setup.sh --reseed-user lab05  # 只重置某位學員
./setup.sh --wipe-user lab05    # 刪帳號重建（保留原密碼）
```

學員密碼會寫在 `LAB_ROSTER`（預設 `/root/lab-roster.csv`，只有 root 看得到）。

### `verify.sh`：驗收環境

```bash
./verify.sh                                         # 檢查 lab01：權限、家目錄、服務 failed、sshd、資源限制
./verify.sh --user lab05 --scenarios --fork-test    # 另外跑第 5 段改壞情境與 fork 炸彈測試
./verify.sh --challange --progress                  # 跑完整闖關流程與進度偵測
```

> `--challange` 最後會對**所有學員**執行 `lab --stop`，上課中不要跑。

### `lab`：學員與講師的進度指令

學員：

```bash
lab               # 看自己的進度
lab hint [N]      # 提示
lab flag '<flag>' # 提交 flag（整串、用單引號）
lab bonus <文字>  # 提交 bonus
```

講師（root）：

```bash
sudo lab --start [帳號…]   # 啟動 evil-killer（闖關開始時用）
sudo lab --stop  [帳號…]   # 停止 evil-killer
sudo lab --all [--json]    # 全班計分板
sudo lab --watch [秒數]    # 計分板自動更新，投影用
sudo lab --reset 帳號…     # 重置某位學員的闖關狀態
```

## 4. 學員文件網站

`site/` 是學員查指令的參考站，部署到 GitHub Pages。

```bash
node scripts/build-site.mjs   # 建置到 dist/
npm run preview:site          # 建置並預覽 http://127.0.0.1:4173
```
